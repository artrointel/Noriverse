# 햄버거 타이쿤

우주 여행 중 배가 고파진 별길 탐사대가 들르는 햄버거 가게를 운영한다. 주문을 확인하고, 여러 패티를 굽는 동안 버거와 음료를 조립해 전달한다. 손님의 주문을 받아 조리해 건네는 흐름은 [붕어빵 타이쿤 소개](https://play.google.com/store/apps/details?hl=ko&id=com.arumgames.bungeoppang)를 참고했다.

| 항목 | 규칙 |
| --- | --- |
| 인원과 시간 | 혼자하기 또는 2~4인 대전·협동. 5·10·15분 또는 무한 모드를 선택한다. 대전은 참가자마다 독립 주방을 운영하고, 영업 종료 시 최고 누적 매출이 승리한다. 무한 모드에서는 먼저 시간이 끝난 참가자도 매출 순위에 포함된다. 협동은 참가자 모두가 한 주방과 영업시간을 공유하며 공동 매출을 기록한다. |
| 난이도 | 기본은 보통이다. 쉬움은 압박 배율 0.7, 어려움은 1.3이다. 방문 빈도와 손님의 대기시간이 닳는 속도, 복잡한 주문이 나올 확률에 배율을 적용한다. 레벨과 카드 효과도 함께 적용된다. |
| 무한 모드 | 주방마다 1분 30초로 시작하고 주문 정확도에 따라 영업 시간을 최대 1분 45초까지 비축한다. 영업 9분 이후에는 방문과 대기 압박이 강해지고, 19분 이후에는 주문별 시간 보너스가 점차 줄어든다. 영업시간에서 준비와 카드 선택, 재접속 대기는 제외된다. 보통은 숙련자 시뮬레이션에서 30분 전후에 시간이 소진되도록 조정했다. |
| 손님 줄 | 개점 뒤 20초 동안 재료를 준비하고 철판을 사용할 수 있다. 보통에서는 처음 네 건을 응대할 때까지 손님이 16초 간격으로 오고, 다른 효과가 없으면 129초 이상 기다린다. 첫 손님은 기본 번·미디움 소고기 패티를 주문하고, 이후에는 원하는 굽기가 달라진다. 최대 네 명이 기다린다. 카드에 따라 후반 주문의 속재료 상한은 3~7개며 패티는 최대 두 장이다. |
| 패티 | 철판 4칸으로 시작하고 확장하면 8칸을 사용한다. 기준 속도는 한 면 7초당 100%이고 개별 패티 속도는 ±10% 범위다. 양쪽 면이 각각 50% 이상이면 평균이 가까운 레어 70%, 미디움 100%, 웰던 130%로 판정한다. 어느 한 면이 200%에 도달하면 탄다. 트레이는 종류별 4개에서 8개로 확장되며 화면에는 최대 5장을 겹쳐 표시한다. |
| 조립대 | 왼쪽 칸으로 시작해 카드로 오른쪽 칸을 연다. 포장지 → 바닥 빵 → 패티와 토핑 → 같은 종류의 윗빵 → 포장 순서다. 선택된 칸을 다시 누르면 맨 위 재료를 제거하며, 패티는 출발 위치나 빈 보관 공간으로 돌아간다. 포장하면 조립이 확정된다. |
| 음료 | 콜라와 사이다 중 주문에 맞는 노즐을 2초 열면 100%가 찬다. 75·100·125%에 가장 가까운 사이즈로 판정한다. 컵과 주문 말풍선에는 같은 세 가지 액체 높이를 표시한다. 200%에 도달하면 컵이 비워진다. |
| 매출 | 빵과 재료 순서를 비교한다. 동일 위치의 일치를 두 주문 길이의 기하평균으로 나눠 코사인 유사도를 구한다. 음료는 종류 58%, 사이즈 42%를 일치점수로 계산한다. 각 항목은 정확하면 정가, 일부만 맞으면 정가 × 0.56 × 유사도³을 지급한다. 재료와 순서가 같으면 패티 굽기 차이는 정가와 콤보에 영향을 주지 않는다. 음료와 모든 패티의 굽기까지 맞으면 주문 정가의 50%를 팁으로 추가한다. |
| 손님 보내기 | 빗자루 배치 카드를 선택하면 손님을 두 번 눌러 50% 확률로 내보낼 수 있다. 손님이 남으면 원래 대기시간의 30%를 남은 시간에서 차감한다. 이 조작으로 떠나는 손님은 30% 확률로 주문 정가를 내고, 매장에는 대기 만료 비용이 생기지 않는다. 같은 주방에서 2.6초 뒤 다시 시도할 수 있다. |
| 콤보 | 주문 전체가 정확하면 콤보가 이어진다. 일부만 맞거나 손님이 기다리다 떠나면 콤보가 끊긴다. 5콤보마다 20초 피버를 발동해 이후 제출 가격을 두 배로 만든다. 진행 중 다시 발동하면 그 시점부터 20초를 새로 센다. |

응대 네 건마다 레벨이 하나 오른다. HUD 위의 초록색 막대가 차면 세 카드가 나오고 하나를 고를 때까지 영업, 조리, 대기와 피버가 함께 멈춘다. 대전에서는 각 주방의 정지 시간이 따로 적용된다. 협동에서는 참가자 중 가장 먼저 확정한 카드가 공동 주방에 적용된다. 기존 경기 스냅샷은 해당 경기가 끝날 때까지 종전 규칙을 사용한다.

카드 선택과 선택 기록은 Phaser 화면에서 표시한다. 카드 아이콘이나 `C`로 선택 기록을 열 수 있고, 선택 카드에는 `1`·`2`·`3`을 사용할 수 있다. 손님의 말풍선을 누르면 내용까지 두 배로 커진다. 3초가 지나거나 다시 누르면 원래 크기로 돌아간다. 확대는 각 브라우저에서 관리한다. 철판이 네 칸일 때는 한 줄을 중앙에 두고, 확장하면 두 줄로 바뀐다.

카드 창에서 다시 뽑기를 누르면 현재 후보를 제외한 카드 세 장으로 바뀐다. 한 경기에서 주방당 세 번까지 사용할 수 있다. 협동에서는 같은 횟수를 공유하며, 남은 횟수는 다음 레벨과 재접속에서도 이어진다. 새 카드가 표시된 뒤 1초가 지나면 선택할 수 있다.

카드 없이 시작할 때는 철판 4칸, 조립대 1칸, 종류별 패티 보관 4개를 쓸 수 있다. 테이블과 버거 보관대는 카드로 연다. 아래 단계부터 각 재료 및 음료 해금 카드가 별개로 나온다. 이미 해금한 재료가 매진되면 그 재료가 들어 있는 대기 주문을 교체하고, 이후 해금 카드를 다시 고를 수 있다. 기본 번과 소고기 패티는 매진 대상에서 제외된다.

고화력 그릴은 선택한 시점부터 철판 위 패티의 굽기 속도를 30% 높인다. 자동화 그릴은 불에 닿는 면이 180%에 도달하면 반대 면에 굽기 여유가 있을 때 뒤집는다. 양면이 모두 180% 이상이면 플레이어가 타기 전에 패티를 내려야 한다. 한 주방에서는 둘 중 한 장만 선택할 수 있다. 철판 칸을 늘리는 카드는 계속 선택할 수 있다.

수익과 방문 수, 대기시간의 퍼센트는 각각 기본값에 합산한다. 수익은 기본 정산액의 최소 10%, 대기시간은 최소 25%를 유지한다. 매장은 100으로 시작하며 패티를 꺼내거나 버릴 때 10, 포장 버거를 버릴 때 30을 지불한다. 대기 만료 때는 음료를 포함한 주문 정가의 절반을 차감한다. 잔액이 0이 되면 해당 주방은 패배한다.

## 입력과 표시

가로 3:2 화면에서 조리대 위로 손님이 왼쪽에서 오른쪽으로 이동해 줄을 선다. 맨 오른쪽 손님이 응대 대상이다. 말풍선의 완성 버거 아래에는 패티와 속재료 아이콘을 쌓는 순서대로 표시한다. 해금 시 재료통 뚜껑을 차례로 열고 새 음료의 로고가 나타난다. 아래 HUD의 첫 줄은 재료 선반이고, 둘째 줄은 철판, 두 칸 패티 트레이, 조립대, 음료 기계, 매립형 전달 버튼이 있는 응대 칸 순서다.

패티는 드래그로 옮기고 두 번 눌러 뒤집는다. 한 면이 200%에 도달할 때 타는 효과음을 재생한다. 트레이에 패티가 두 장 이상 있으면 엔진 화면에서 굽기를 비교하고 원하는 한 장을 고른다. 한 장이면 탭으로 바로 조립 칸에 옮긴다. 주문 말풍선과 조립 목록의 굽기는 레어·미디움·웰던 패티 이미지로 구분한다. 조립 칸에 포장지와 바닥 빵을 깔고 말풍선의 버거를 아래부터 따라 만든다. 바닥 빵에 패티를 쌓으면 같은 빵 선택으로 윗빵을 올릴 수 있다. 조립 칸을 두 번 눌러 포장한다. 노즐을 누르면 음료가 나오고 다시 누르면 멈춘다. 포장된 버거와 음료를 응대 칸에 준비한 뒤 맨 앞 손님에게 건넨다. 맨 앞 손님이 떠나도 준비한 음식은 응대 칸에 유지된다.

## 리소스와 동기화

철판을 한 번 누르면 패티 아래로 뒤집개가 나타난다. 포인터를 뗀 뒤 프레임 시간과 독립적으로 260ms 동안 두 번째 입력을 기다린다. 두 번 누르면 뒤집고, 한 번이면 구운 패티와 뒤집개가 트레이로 이동하는 180ms 애니메이션을 재생한다. 각 패티 트레이에서 조립대로 끌면 그 종류의 맨 위 패티가 옮겨진다. 트레이 선택 창에서 패티를 왼쪽 아래 휴지통으로 끌면 그 패티만 버린다.

보관대 위 버거를 다른 칸으로 끌면 이동하고, 대상 칸에 버거가 있으면 두 버거가 자리를 바꾼다. 제출 칸의 버거를 누르면 직전에 있던 보관대나 조립 칸으로 되돌아간다. 원래 칸은 제출하거나 버거를 꺼낼 때까지 비워 둔다. 협동에서 조립 대상 칸은 각 참가자가 따로 고른다. 픽셀 크기는 경기 중 설정에서 바꾸며 각 브라우저에 저장한다.

손님 반응은 주문과 제출 메뉴의 차이에 맞는 한국어·영어 후보 중에서 고른다. 식사 중에는 질문이 아닌 후보를 추가로 말할 수 있다. 무료 제공 대사가 선택되면 손님은 음식을 받지만 매출에 반영되지 않고 같은 주문을 기다린다. 요청하지 않은 음료에 감사하는 대사가 선택되면 팁 1점을 더한다.

[버거 타이쿤 이미지](../apps/web/src/assets/burger/)는 내장 ImageGen으로 생성했다. 매장과 주방, 재료와 굽기 단계, 별길 탐사대 손님 스프라이트는 카툰 원본을 사용한다. 입력 구역은 렌더링에서 숨기고, 손님이 말하는 약 2초 동안 기존 말풍선의 주문 그림 자리에 대사를 표시한다.

패티 아틀라스는 기존 카메라 각도를 유지한 다섯 굽기 단계의 소고기와 닭고기를 다시 생성한 것이다. 소고기는 짙고 매끈한 원형이며 닭고기는 아이보리색과 불규칙한 외곽을 사용하고, 탄 단계는 숯빛이다. 오른쪽 재료 통의 닭고기는 아틀라스의 생패티를 참고해 넓고 비대칭적인 굴곡과 도톰한 옆면을 살렸다. 카드 아틀라스는 민트·주황·자주색 카드 면과 청록색 패널, 주방 설비와 손님 효과를 구분하는 소품 아이콘을 생성한 것이다.

작업대의 재료통 열두 개와 철판·트레이·도마·음료 기계·응대 쟁반은 같은 시점과 조명 아래 그렸다. 마름모 포장지와 손님 네 종류의 정면 대기·눈깜빡임·오른쪽 걷기 네 프레임은 독립 이미지다. 배경·캐릭터·재료·텍스트를 같은 격자에서 합성한다. 화면 위 픽셀 크기 슬라이더는 물리 화면 픽셀 기준 1~6칸을 비교하며, 기본값은 2칸이다. 현재 표시 영역에 맞춰 내부 3:2 해상도를 즉시 재계산한다. 이 값은 브라우저에 저장하거나 다른 참가자에게 전송하지 않는다. 손님 대기시간은 발치의 진행 막대로 표시한다. 조립용 재료를 누르면 통에서 도마까지 짧은 포물선을 그리며 이동한다. 익은 패티를 누르면 철판에서 트레이로 옮기고, 트레이의 패티를 누르면 도마로 옮긴다.

다리 전체가 보이는 테이블과 의자를 사용한다. 여섯 테이블을 두 줄에 배치하고 경기 시드에 따라 위치를 조금씩 바꾼다. 주문을 받은 손님은 응답 후 선착순으로 빈 좌석에 앉아 9~11초간 식사한 뒤 오른쪽으로 걸어 나간다. 식사 중에는 주문 정확도에 따라 하트, 기쁨, 미소, 당황, 실망 중 하나를 띄운다. 방장의 일정으로 식사 상태를 유지하고, 연결 대기 중에는 기존 경기 시계와 함께 멈춘다.

주방 효과음은 원음을 잘라 제작한 CC0 실물 녹음으로 공용 효과음 볼륨을 사용한다. 종이 펴기·포장·폐기는 [Anthousai의 종이 녹음](https://freesound.org/people/Anthousai/sounds/398897/), 철판의 연속 소리는 [BenjaminNelan의 팬 녹음](https://freesound.org/people/BenjaminNelan/sounds/353124/), 집게·쟁반·누름은 [NichelleMedia의 금속 녹음](https://freesound.org/people/NichelleMedia/sounds/614853/), 탄산과 넘침은 [Anthousai의 음료 녹음](https://freesound.org/people/Anthousai/sounds/398985/), 제출과 시작·승리 알림은 [WillFitch1의 오븐 벨 녹음](https://freesound.org/people/WillFitch1/sounds/144883/)을 사용한다.

대전에서는 방장이 입력 순서, 타이머, 판정과 매출을 확정한다. 첫 주문과 주문 난수를 공유하고, 각 주방의 응대 속도에 따라 난도와 대기열이 따로 변한다. 물리 프레임 전송 없이 입력과 변경된 상태를 기존 방 통신으로 전달한다. 재접속 대기 중에는 타이머를 멈추고, 경기 종료 후 공용 결과·재경기·방 랭킹을 사용한다. 유사도 감점과 후반 대기시간은 실기기 대전의 주문 완료율을 확인한 뒤 조정할 수 있다.

협동에서는 방장이 공용 주방 상태 한 벌의 입력을 차례로 적용한다. 한 사람이 올린 패티를 다른 사람이 뒤집을 수 있다. 트레이 선택 창과 조립 대상 칸은 각자 화면에 남으며 선택한 패티의 식별자만 전송한다. 같은 패티의 이전 면을 뒤집으려는 입력이나 다른 사람이 이미 집은 패티를 고르는 입력은 적용하지 않는다. 협동을 완료한 참가자의 프로필은 공동 매출이 자신의 기존 최고 매출을 넘을 때만 갱신한다. 협동 결과는 대전 승패·승률·전적·플레이 시간과 방 랭킹에 집계하지 않는다.

주방 배경은 한 장의 카툰 이미지에 매장 타일 바닥과 준비대, 매립형 쓰레기통 입구, 8칸 보관대, 쟁반에 매립된 전달 버튼을 함께 그린다. 보관대를 해금하기 전에는 내장 ImageGen으로 생성한 평평한 녹색 조리대를 해당 영역에 합성한다. 도마 위 포장지의 실제 너비를 버거보다 넓게 맞췄다. 오른쪽 패티 트레이는 소고기와 치킨을 독립적으로 쌓는다. 포장 버거 아래에는 소고기와 닭고기 아이콘을 포함한 재료를 층순서대로 표시한다. 보관된 버거를 누르면 응대 칸으로 꺼낸다. 쓰레기통으로 끌어 폐기하고 보관대의 버거는 위로 끌어도 폐기한다. 주문 말풍선은 Phaser에서 주문 크기에 맞춰 그린다. 게임 엔진 텍스트는 Sketch Jua를 사용한다.

손님 아틀라스는 원본에서 각 자세의 실루엣을 따로 추출하고, 발의 높이를 맞춘 뒤 투명 여백과 4px 간격을 두었다. 재료·패티는 새 카툰 원본에서 투명 가장자리의 잔여 픽셀을 정리해 패킹했다. Phaser 내부에서 스프라이트를 선형 샘플링한 다음, 합성된 화면은 지정된 물리 픽셀 크기로 확대한다. 공통 접촉 음영은 스프라이트의 불투명 범위와 바닥 위치에서 계산하며, 철판·도마·바닥의 강도와 들어 올린 높이를 반영한다. 같은 텍스처 기반 음영을 Canvas와 WebGL에 적용한다.
