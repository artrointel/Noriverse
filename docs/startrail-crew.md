# 별길 탐사대 게임 기획서

**별길 탐사대**는 친구와 함께 적대 외계인과 괴물이 장악한 행성에 내려가 주민을 구조하고 끊긴 항로를 되살리는 2D 탑다운 협동 슈팅 게임이다. 키보드로 이동하면서 마우스로 조준·사격한다. 한 사람이 시설을 복구하는 동안 다른 사람이 길을 지키는 순간이 협동의 중심이다.

한국어 게임명은 **별길 탐사대**로 확정했다. 영문 게임명 후보는 세계관의 탐사대 명칭인 **Startrail Crew**다. 게임 요구사항을 이 문서에서 계속 다듬고, 임무·전투·연출과 검증 기준을 합의한 뒤 개발을 시작한다. 수치는 [밸런스 테이블](startrail-crew-balance.md), 캐릭터의 원래 서사와 외형은 [별길 탐사대 설정집](characters.md)에서 관리한다.

## 세계관

별길 탐사대는 항성, 혜성, 위성을 닮은 작은 생명체들이 관측과 발견을 공유하며 미지의 우주로 항로를 넓혀 가는 모임이다. 적대 세력이 항로 중계소를 점거한 틈에 에너지를 먹는 괴물 무리가 몰려들면서 여러 행성의 전력과 통신이 끊긴다. 탐사대는 고립된 행성에 착륙해 주민을 구조하고 시설을 되찾아 안전한 길을 다시 연다. 임무를 마치면 궤도 지도의 연결선이 밝혀져 되찾은 항로와 다음 목적지를 보여준다.

Alien Swarm의 참고 범위는 탑다운 시점에서 여러 사람이 역할을 나누는 협동 경험이다. 탐사대원, 생물, 임무, 맵, 장비, UI와 사운드는 놀이버스 세계관에 맞춰 새로 설계한다. [Valve의 Alien Swarm 공식 Steam 페이지](https://store.steampowered.com/app/630/Alien_Swarm/)

## 핵심 플레이

1. **착륙한다.** 탐사대원을 고르고, 착륙 지점에서 이동과 사격을 익힌다.
2. **목적지로 전진한다.** 지형과 시설의 배치를 읽어 통로를 찾고, 적을 밀어내며 진행 경로 주변의 서브미션을 해결한다. 시설을 작동시키기 전에 주변을 정리할지, 바로 복구를 시작할지 결정한다.
3. **시설을 되찾는다.** 누구나 복구 패널을 조작할 수 있다. 조작 중에는 사격할 수 없고, 자리를 벗어나면 조작을 멈춘다. 작동을 시작하면 적이 몰려오므로 한 사람이 복구하고 다른 사람이 길을 지킨다.
4. **다음 구역으로 이동한다.** 필수 서브미션을 완료하고 종료 지점에 도착하면 다음 스테이지로 넘어간다. 마지막 스테이지를 마치면 복구 지점, 구조 여부, 소요 시간과 밝혀진 항로를 보여준다.

| 입력 | PC 기준 |
| --- | --- |
| 이동 | `WASD` 방향으로 이동한다. 조준 방향을 유지한 채 옆이나 뒤로 이동할 수 있다. |
| 조준·공격 | 마우스 커서가 조준 방향, 캐릭터의 응시 방향과 손전등 방향을 함께 결정한다. 왼쪽 버튼으로 장비한 무기를 사용한다. |
| 상호작용 | `E`로 패널을 조작하고, 구조 대상과 대화하거나, 행동 불능 상태인 동료를 일으킨다. |
| 구르기 | 이동 방향 키를 누른 채 `Space`를 누르면 그 방향으로 짧게 구른다. 도착 직전에 감속하고 일어설 때까지 이동 입력과 사격이 제한된다. |
| 미니맵 | `Tab`으로 숨김, 상세 지도, 오버레이를 순환한다. 탐사대원 위치와 발견한 지역을 확인할 수 있다. |

협동에서 한 명이 행동 불능이 되면 다른 사람이 가까이서 일으킬 수 있고, 탐사대 전원이 행동 불능이 되면 임무에 실패한다. 혼자하기는 같은 목표를 쓰며 적의 수와 출현 간격을 조정한다. 복구 장치를 잠시 떠났다가 다시 이어서 조작하는 방식도 검증한다.

## 2D 물리와 충돌

- 지면 위 중력이 없는 2D 물리 월드를 사용한다. 지형, 벽과 닫힌 문은 고정 충돌체로, 탐사대원과 몬스터, 밀 수 있는 상자와 장애물은 질량이 있는 동적 충돌체로 구성한다.
- 플레이어와 몬스터가 접촉해 밀고 밀릴 때 두 물체의 위치가 물리적으로 바뀐다. 키보드 이동과 AI 추격도 같은 충돌 월드를 거친다. 벽에 몰린 상황에서 겹침이나 통과 없이 밀어내기가 동작해야 한다.
- 공격이 적중하면 타격 방향으로 충격량을 적용한다. 같은 타격을 받더라도 가벼운 대상이 무거운 대상보다 더 빠르고 멀리 밀린다. 질량·감쇠·밀림 제한과 무기별 충격량은 밸런스 테이블에서 관리한다. 미끄러짐이 길어져 조작이 둔해지거나 팀원이 좁은 길을 장시간 막는 문제를 첫 검증에서 살핀다.
- **검증 후보는 Phaser 내장 Matter Physics**다. 질량과 동적 강체 충돌을 같은 월드에서 처리할 수 있는 점을 근거로 잡았다. 동시 적 수가 늘어날 때의 처리 시간과, 빠르게 움직이는 물체가 얇은 지형을 통과하지 않는지 확인한 뒤 채택한다. [Phaser Matter Physics 공식 문서](https://docs.phaser.io/phaser/concepts/physics/matter)

## 무기와 특수장비

장비는 근접무기, 주무기, 부무기와 공격 보조용 특수장비로 구성한다. 방어구는 향후 검토 항목이다. 장비별 피해·공격 속도·충격량을 독립적으로 조정할 수 있게 한다.

| 분류 | 지원 범위 |
| --- | --- |
| 근접무기 | 주먹을 기본 근접 공격으로 두고, 나이프·몽둥이·도끼·전기톱·광선검을 지원한다. 공격 범위, 속도와 밀어내기로 차이를 만든다. |
| 주무기 | 총기류를 사용한다. 현대식 소총·산탄총 계열부터 펄스총·에너지총 같은 SF 무기까지 사거리, 연사, 범위가 다른 무기를 갖춘다. |
| 부무기 | 권총·소형 펄스총 등의 총기류를 사용한다. 주무기와 다른 사거리와 조작감을 주는 보조 슬롯이다. |
| 특수장비 | 수류탄, C4, 드론, 트랩, 포탑을 지원한다. 한 번에 범위를 공격하거나, 일정 구간을 지키거나, 적의 이동을 방해하는 방식으로 차이를 둔다. |

## 지도와 스테이지

한 임무는 맵이 서로 다른 여러 스테이지로 이어진다. 각 스테이지에는 시작 위치와 종료 위치가 있다. 주요 진행로 주변의 전력 복구, 통로 개방, 구조 같은 필수 서브미션을 해결하고 종료 위치에 도달해야 완료한다. 짧은 갈래길은 우회나 탐색에 쓰고 본선과 다시 연결한다. 스테이지가 바뀌면 이전 맵의 종료 장소를 다음 맵의 시작 장소로 이어서 탈환의 흐름을 보여준다.

배경은 전반적으로 어둡게 유지하고, 벽·기둥·격납 상자·문과 같은 지형지물로 통로와 전투 공간을 나눈다. 바닥의 배선, 조명의 흐름, 출구와 시설의 실루엣으로 어느 쪽으로 갈 수 있는지 읽히게 한다. 길 찾기의 기준은 배경만 보고도 다음 방향을 짐작할 수 있는지다.

화면 중앙의 미니맵은 전투 화면 위에 반투명으로 표시하며, 탐사대원별 현재 위치를 아이콘으로 구분한다. HUD의 임무 목표·복구 진행도·팀원 상태와 함께 엔진에서 렌더링한다.

## 아트, 픽셀 렌더러와 조명

- **텍스처.** 모든 이미지를 귀여운 카툰 스타일의 아틀라스로 제작한다. 캐릭터·몬스터·지형지물·장비·인게임 UI에 공통 팔레트, 빛 방향, 시점과 비례 기준을 적용한다. 윤곽은 색면과 명암으로 구분하고 아웃라인은 쓰지 않는다. 같은 대상의 프레임은 발밑 기준점을 맞추고 이웃 프레임이 비치지 않도록 여백을 둔다.
- **애니메이션.** 인게임 UI용 이미지는 정적으로 사용할 수 있다. 월드의 캐릭터·몬스터·장비·환경 오브젝트는 각 상태에 맞는 애니메이션을 갖춘다. 캐릭터와 몬스터는 대기·이동·공격·피격·행동 불능을, 문·패널·승강기는 작동·고장·복구를 움직임으로 보여준다.
- **픽셀 렌더러.** 카툰 원본을 같은 월드 픽셀 격자로 출력한다. 스프라이트·이펙트·라이트와 그림자를 같은 렌더링 해상도에서 합성하고 최종 확대에는 최근접 샘플링을 쓴다. 물리 좌표는 연속적으로 유지해 충돌 위치가 화면의 픽셀 격자에 따라 달라지지 않게 한다.
- **손전등과 시야.** 플레이어의 응시 방향에 맞춰 손전등 원뿔이 회전하고 정면을 밝힌다. 벽과 닫힌 문은 빛을 가려 뒤에 사각지대를 만든다. 조명이 닿지 않는 곳은 어둡게 유지하고, 팀원의 손전등과 복구된 시설 조명은 실제로 닿는 구역을 밝힌다. 조명 범위와 주변광은 통로와 위험 예고를 읽을 수 있게 조정한다.
- **그림자.** 월드의 모든 오브젝트에 공통 그림자 렌더링을 적용한다. 캐릭터·괴물·장비·소품은 위치와 움직임을 따라 바닥에 접지 그림자를 드리운다. 벽·기둥·큰 장애물의 그림자는 광원 방향과 빛 가림을 반영한다. 라이트와 그림자는 엔진에서 합성해 손전등 방향과 시설 전원 상태 변화에 대응한다.

## 첫 임무 · 얼음 아래의 구조 신호

얼음 위성의 지하 관측소에서 구조 신호가 올라온다. 지표 중계소와 관측소 승강기의 전력이 끊겼다. 파루미의 안내로 중계소를 되찾고 얼음 아래로 내려가 주민을 구조한다.

| 스테이지 | 시작 위치와 경로 | 필수 서브미션과 종료 위치 |
| --- | --- | --- |
| **1-1 지표 중계소** | 남서쪽 착륙대에서 출발한다. 남쪽 정비로와 서쪽 얼음 통로 중 어느 쪽으로 가도 중앙 발전기에 닿는다. 서쪽 탐사 구역과 남동쪽 보급 창고는 막다른 지형이고, 중앙 발전기 북쪽 우회로는 종료 구역 쪽에서 동쪽 통로와 합류한다. | 발전기를 켜고 전력이 돌아오는 동안 방어한다. 복구가 끝나면 동쪽 차단문이 열리고 **지하 관측소행 승강기**에 도달해 완료한다. |
| **1-2 얼음 아래 관측소** | 1-1에서 탄 승강기의 지하 정류장에서 시작한다. 지표와 다른 맵으로, 파루미의 교신을 들으며 얼음 물길과 좁은 관측 통로를 지나간다. | 고립된 주민을 찾아 구조하고 비상 승강기의 전력을 복구한다. 주민과 함께 **지표행 비상 승강기**에 도착하면 임무가 끝나고 궤도 지도에서 첫 항로가 켜진다. |

## 1-1 지표 중계소 구현

PC에서 [지표 중계소](http://localhost:5173/startrail/)를 연다. 1-1의 지도는 **36×28 타일**로 이전 샘플의 세 배 면적이다. 중앙 발전기 근처에서 `E`를 길게 눌러 복구를 시작한다. 방어 범위 안에서 복구를 마치면 잠겨 있던 차단문이 열리고, 승강기에 도착하면 결과가 표시된다. 방을 쓰는 협동과 1-2 전환은 차기 구현 항목이다.

- `WASD`로 이동하고 마우스로 조준한다. 좌클릭은 주무기, 우클릭은 정찰 권총이다. 착륙대 옆 데저트 이글에 가까이 가서 `E`를 누르면 기존 주무기와 탄창 상태를 바닥에 내려놓고 교체한다. `R`은 마지막으로 사용한 무기를 재장전한다. 펄스 카빈은 광선을, 데저트 이글과 정찰 권총은 짧은 잔상을 남기는 탄환을 발사한다. 탄환의 이동 중 충돌을 판정하며, 탄피와 탄두는 바닥에 떨어진다.
- `WASD` 또는 방향키를 누른 채 `Space`를 누르면 입력한 방향으로 구른다. 두 방향을 동시에 누르면 대각선으로 이동한다. 벽이나 장애물이 길을 막으면 일찍 감속하고 일어서며, 회피 동작 중에도 피해를 입을 수 있다. 솔오리의 체력이 바뀌면 발밑에 체력바가 1초간 나타난다.
- 보급 상자와 얼음 결정을 공격해 파괴할 수 있다. 파괴된 물체는 잔해를 남기며 물리 충돌과 빛 가림에서 빠진다. 중계소와 승강기는 임무 시설로 유지한다.
- 서쪽 탐사 구역과 남동쪽 창고의 보급품은 `E`로 한 번 받을 수 있다. 체력을 회복하고 두 무기의 탄창을 채운다.
- 손전등은 중앙에서 가장 밝다. 바라보는 방향에서 벗어난 영역은 플레이어와의 거리가 멀수록 점차 어두워진다. 물체의 뒷면부터 바닥에 그림자를 드리우며, 가까이에서 사용할 수 있는 발전기와 무기는 노란 윤곽과 옅은 노란색으로 표시한다. 조명의 거리와 밝기는 밸런스 테이블에서 관리한다. [1-1 적용값](startrail-crew-balance.md#1-1-적용값)
- `Tab`으로 상세 지도, 타일과 표식만 20% 불투명도로 보이는 오버레이, 지도 닫기를 순환한다. 오버레이의 플레이어 표식은 화면 속 캐릭터의 발 위치와 일치하고, 주변 지도가 이동에 따라 상하좌우로 움직인다. 오버레이를 켠 상태에서도 이동과 사격이 가능하다.
- **픽셀 크기**는 실제 화면의 픽셀을 기준으로 월드에 1~5픽셀 블록을 적용한다. 바닥, 스프라이트, 조명과 가림 마스크를 고정 래스터에 최근접 샘플링으로 그린 뒤 정수 배율로 출력한다. HUD와 지도는 별도 캔버스에서 기기 해상도로 그린다. **웹뷰 해상도**와 **전체 화면**으로 표시 크기를 바꿀 수 있다.

### 1-1 적 구성

| 적 | 교전 방식 |
| --- | --- |
| 얼음 진드기 | 좁은 길에서 추격해 접촉으로 공격한다. |
| 빙하 멧돼지 | 앞쪽에 돌진 예고가 보이면 직선으로 돌격한다. |
| 균열 정찰병 | 조준선을 예고하고 에너지탄 한 발을 쏜다. 가까이 다가가면 거리를 벌린다. |
| 중장 경비병 | 긴 예고 뒤 세 방향으로 에너지탄을 발사한다. |
| 서리 포자 | 부풀면서 둥근 범위를 예고한 뒤 냉기 파동을 일으킨다. |
| 빙각 굴착충 | 몸을 낮춘 뒤 짧고 빠르게 돌진한다. |

여섯 종 모두 피격 뒤 쓰러지는 전용 자세를 쓴다. 적은 쓰러지기 시작하면 충돌과 공격 판정에서 빠지고, 떨어진 자리에 잠시 보였다가 사라진다.

## 첫 검증 범위와 플랫폼 연결

첫 검증은 PC 브라우저에서 **혼자하기와 실제 2인 친구 방**으로 진행한다. 첫 임무의 맵 두 개, 조작 가능한 캐릭터 두 명, 주먹과 기본 총기, 작은 무리형·큰 돌진형을 우선 사용한다. 공개 목표는 최대 4인 협동이다. 이후 적대 외계인과 무기·특수장비 확장, 추가 행성, 3~4인 밸런스와 모바일 가로 화면 조작을 검증한다.

- **엔진과 플랫폼.** 모든 플레이 기능과 게임 로직은 Phaser 게임 모듈이 담당한다. 입력·물리·전투·AI·장비·스테이지·조명·HUD·미니맵과 게임 결과 판정도 여기에 포함된다. React 웹단은 라이브러리·대기실·게임 마운트·공통 결과 화면을 담당하고, 게임에서 내보낸 확정 결과를 표시한다. 선택된 게임의 Scene과 리소스만 로드한다.
- **온라인 판정.** 기존 친구 방의 WebRTC 직접 연결을 우선한다. 각 브라우저는 조작에 즉시 반응하고, 호스트 엔진의 물리 월드가 충돌·밀림·명중·AI·임무 진행의 최종 상태를 정한다. 위치와 속도, 현재 스테이지와 서브미션 상태를 필요한 주기로 동기화한다.
- **복구와 비용.** 공통 연결 대기·중계 전환 흐름을 재사용한다. 재접속 시 호스트가 확정한 맵과 동적 물체, 적, 시설, 구조 진행을 복원한 뒤 이어서 플레이한다. P2P와 중계에서 입력 지연, 오차 보정과 트래픽을 비교해 갱신 빈도를 정한다. 검증은 기존 인프라와 무료 이용 한도 안에서 진행한다. [놀이버스 기술 검토](technical-design.md)

## 개발 착수 시 확인할 기준

| 검증 | 처음 확인할 동작 |
| --- | --- |
| 조작과 물리 | 이동하면서 독립 조준하고 공격한다. 같은 타격에 질량별로 밀림이 달라지고, 플레이어와 괴물이 서로 밀려 이동한다. 벽 근처와 좁은 통로에서도 충돌이 유지된다. |
| 조명과 시인성 | 마우스를 돌리면 캐릭터와 손전등이 함께 돌아간다. 벽 뒤는 어둡고 움직이는 대상의 그림자가 따라간다. 어두운 구간에서도 길과 돌진 예고를 구별하고 미니맵에서 팀원 위치를 확인한다. |
| 협동의 필요성 | 실제 두 사람이 한 명은 패널을 조작하고 한 명은 방어하는 행동을 자연스럽게 선택한다. 역할을 바꿔도 진행할 수 있다. |
| 지도와 스테이지 전환 | 초보 두 사람이 방향 안내를 끈 상태에서 배경을 보고 길을 찾고, 서브미션을 클리어해 종료 지점에 도달한다. 1-1의 승강기에서 1-2의 새 지도로 이어지는 맥락을 알아볼 수 있다. |
| 혼자하기 | 같은 경로에서 복구와 방어를 번갈아 수행해 완주할 수 있다. |
| 온라인 복구 | 전투·시설 복구·스테이지 전환 중 참가자 연결을 끊고 다시 연결했을 때 양쪽의 맵, 물체 위치, 진행 상태가 일치한다. 직접 연결과 중계에서 같은 판정이 유지되는지 확인한다. |

개발 전에 장비 교체와 특수장비의 입력, 스테이지 사이에 이어지는 체력·탄약 상태, 외계인 첫 등장 구간을 확정한다. 개발에 들어가면 좁은 통로 한 곳에서 먼저 이동·밀림·손전등과 돌진 예고를 함께 검증하고, 이어서 중계소 복구와 스테이지 전환을 확인한다.
