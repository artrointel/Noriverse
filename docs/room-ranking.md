# 방 랭킹보드 점수

## 집계와 동점 기준

방이 유지되는 동안 끝난 온라인 경기를 집계한다. 같은 방에서 게임을 바꿔도 점수는 이어진다. 전체 점수가 같으면 승수가 많은 순으로 표시하며, 승수도 같으면 동일한 참가자 키 순서를 유지한다. 방장은 경기 종료 시 점수를 확정하고, 참가자는 방 경기 기록 동기화로 같은 점수를 받는다. 방이 종료되면 방 안의 경기 기록과 랭킹도 사라진다.

## 화면과 경기 기록

대기실 상단 게임 카드의 참가자 목록 위에 랭킹보드를 배치한다. 첫 점수가 기록되면 펼쳐진 상태로 표시하며 사용자가 접을 수 있다. **기록 보기**에서는 경기별 결과와 플레이 시간, 참가자별 획득 점수를 확인한다.

경기 화면의 랭킹 팝업 상단에는 방제를 표시한다. 경기 기록이 아직 없으면 순위 없이 참가자 목록을 보여 준다. 상위 세 자리에는 프로필 캐릭터와 금·은·동 메달을 표시하고, 1위 카드의 폭죽은 터지는 위치를 바꾸며 반복한다. 경기 결과로 순위가 바뀌면 랭킹 버튼 옆에서 대표 변동을 3초 동안 알려 준다.

## 점수 표

| 결과 | 지급 점수 |
| --- | ---: |
| 승리 | 50점 |
| 무승부 | 30점 |
| 패배 | 10점 + 진행률 × 30점 (반올림) |

진행률은 0~100%로 제한한다. 협동으로 승리한 경우 기존 게임 판정에서 승자로 처리된 사람은 각각 50점을 받는다.

| 게임 | 패배 점수에 반영하는 진행률 |
| --- | --- |
| 오목 | 가로·세로·대각선 중 가장 길게 연결한 자기 돌 수를 4로 나눈 값 |
| 오델로 | 양쪽의 초기 돌 2개씩을 뺀 뒤, 자기 돌의 비중이 절반에 가까워진 정도 |
| 체스 | 잡은 상대 기물 가치의 합을 상대 초기 기물 가치 39로 나눈 값. 폰 1, 나이트·비숍 3, 룩 5, 퀸 9 |
| 알까기 | 2인은 상대 돌을 떨어뜨린 비율. 3~4인은 탈락 순서에 따라 첫 탈락부터 마지막 탈락까지 차등 지급 |
| 사천성 | 시작 타일 수 대비 자신이 제거한 타일의 비율. 협동에서도 타일을 제거한 플레이어에게 진행률 반영 |
| 메모리 | 시작 카드 수 대비 자신이 제거한 카드의 비율 |
| 별젤리 | 경기 내 최다 제거 수 대비 본인이 제거한 젤리 수의 비율 |
| 두더지게임 | 경기 내 최고 득점 대비 본인의 득점 비율. 음수는 진행률 0%로 처리 |
| 햄버거 타이쿤 대전 | 경기 내 최고 매출 대비 본인의 누적 매출 비율. 시간제와 무한 대전에 적용 |
| 캐치마인드 | 경기 내 최고 득점 대비 본인의 맞히기 점수 비율 |
| 라이어 게임 | 힌트 제출 10점, 투표 10점, 시민의 정확한 라이어 지목 또는 라이어의 정답 추측 20점의 합을 40으로 나눈 값 |

햄버거 타이쿤의 대전 결과는 방 랭킹에 반영하고 프로필에 승패를 저장한다. 협동 결과는 기존 최고치를 넘었을 때 프로필의 공동 최고 매출만 갱신한다. 혼자하기는 연습으로 집계에서 제외한다.

라이어 게임 전용 HUD에는 같은 방에서의 **라이어 누적 점수**를 별도로 표시한다. 경기 승리 100점에 위 참여 점수(최대 40점)를 더해 라이어 경기마다 누적한다. 방 랭킹에는 공통 50점 기준 점수만 합산한다.

프로필이 있으면 공개 프로필 ID를 사용하고, 익명 참가자는 방의 재접속 자리가 유지되는 동안 동일한 공개 참가자 ID를 사용한다. 개발용 목업 경기는 같은 점수표를 사용하며 방 안의 테스트 랭킹과 테스트 경기 기록에 집계한다. 목업 자리는 실제 참가자와 분리해 표시한다. 일반 랭킹, 프로필 전적과 뱃지에는 실경기를 집계한다. 점수 필드가 없는 구버전 경기 기록에는 승리 50점, 무승부 30점, 패배 10점을 적용한다.
